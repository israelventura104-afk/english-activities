## How to add a module

1. Put it in a stable folder (`present-simple/`, not `10-present-simple/`).
2. Give it a **track** (General / Business / Exam) and a **stage** (`A1.1`, `A1.2`, `A2`, `B1`…).
3. Add one row in that stage on `index.html`. Do not renumber the menu.
4. A pack that mixes levels (Conditionals) stays on **Tracks**. File each lesson in the catalog too, when useful.

Do not put personal or apartment projects in this portal.
