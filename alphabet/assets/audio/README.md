# Letter name audio

Record **the English letter name** (what you say when you spell), not the sound inside a word.

One file per letter, lowercase, mp3:

```
a.mp3  b.mp3  c.mp3  d.mp3  e.mp3  f.mp3  g.mp3
h.mp3  i.mp3  j.mp3  k.mp3  l.mp3  m.mp3  n.mp3
o.mp3  p.mp3  q.mp3  r.mp3  s.mp3  t.mp3  u.mp3
v.mp3  w.mp3  x.mp3  y.mp3  z.mp3
```

| File | Say |
| --- | --- |
| h.mp3 | aitch |
| j.mp3 | jay |
| w.mp3 | double u (the whole name in one clip) |
| y.mp3 | why |
| z.mp3 | zee *or* zed — whatever you teach |

Quiet room, phone is enough. One name per clip, no “A as in apple”. Same distance and volume for all 26.

Until a file is here, the lesson falls back to the browser voice.
